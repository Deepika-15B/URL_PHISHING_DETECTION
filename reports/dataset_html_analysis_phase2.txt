Potential preprocessing requirements
-----------------------------------
- Remove or impute missing values before model training; missingness is present in several HTML-derived features.
- Address duplicate rows and duplicate URLs to avoid leakage and redundancy.
- Review constant columns; they offer no predictive value and can be dropped.
- Handle high-cardinality text features such as URL, domain, and title carefully.
- Confirm the binary target encoding and keep the mapping consistent across the pipeline.

Potential feature engineering opportunities
----------------------------------------
- Create domain reputation indicators from TLD and domain characteristics.
- Derive URL structure ratios and obfuscation signatures beyond the raw counts.
- Engineer HTML layout and form-related indicators such as iframe-to-image ratios or form submission patterns.
- Create interaction features between URL and HTML signals.
- Aggregate counts of external references, scripts, styles, and images into normalized ratios.

Suitability for HTML-based phishing detection
-------------------------------------------
- The dataset contains a rich set of HTML, URL, and security-related features, making it suitable for phishing detection research.
- The presence of both structural page features and URL/domain signals supports a multi-signal detection approach.
- The dataset appears well suited for rule-based analysis, exploratory modeling, and downstream implementation, provided the data quality issues are addressed.

Recommendations for the next implementation phase
------------------------------------------------
- Keep the URL column intact and use it as a primary identifier and audit field.
- Create a preprocessing pipeline that handles missing values, duplicate records, and constant columns explicitly.
- Define and document a consistent label mapping before any implementation work.
- Investigate whether the HTML-derived text fields should be normalized, tokenized, or transformed before modeling.
- Split the dataset into training, validation, and test folds only after the preprocessing plan is finalized.
