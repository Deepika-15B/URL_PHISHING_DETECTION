EXACT ROOT CAUSES SUMMARY
================================================================================

ISSUE 1 ROOT CAUSE (Every site classified as Phishing, 100% Confidence, Threat Score 100):
--------------------------------------------------------------------------------
Feature Key Mismatch in Feature Dict Assembly (`backend/routes/predict.py`):
1. `backend/routes/predict.py` populates the model input DataFrame by querying
   `url_feats.get(col, 0.0)` for each column in `top20_features`.
2. `top20_features.pkl` consists of 20 PHIUSIIL dataset features (`LineOfCode`,
   `NoOfImage`, `NoOfJS`, `NoOfCSS`, `IsHTTPS`, `HasCopyrightInfo`, etc.), whereas
   `url_feats` contains 101 URL lexical features (`qty_dot_url`, `qty_slash_url`, etc.).
3. Because 0 of the 20 `top20_features` exist in `url_feats`, `url_feats.get()`
   defaults to `0.0` for all 20 features, resulting in an all-zero feature vector
   `[0.0, 0.0, ..., 0.0]` for EVERY site.
4. `scaler_phase2_v2.pkl` scales the all-zero vector to negative z-scores
   (e.g., `[-2.72, -0.34, ..., -0.84]`).
5. `fnn_phase2_v2.keras` outputs `raw_prob = 0.000000` for this scaled zero vector.
6. The prediction logic (`prediction_label = "Legitimate" if raw_prob >= 0.5 else "Phishing"`)
   evaluates `0.000000 < 0.5`, classifying every single URL as "Phishing" with
   `phishing_probability = 1.0 - 0.0 = 1.0` (100% Confidence, Threat Score 100).

ISSUE 2 ROOT CAUSE (No browser screenshot ever saved in reports/screenshots/):
--------------------------------------------------------------------------------
Premature Page Closure & Empty Context Page List:
1. `HTMLFeatureExtractor.fetch_rendered_html(url)` in `utils/html_feature_extractor.py`
   closes the Playwright page in a `finally:` block (`page.close()`) immediately after
   retrieving the page HTML.
2. In `backend/routes/predict.py`, `capture_page_screenshot(pipeline, url)` is called
   AFTER `pipeline.extract(url)` completes.
3. `capture_page_screenshot` inspects `pages = extractor._context.pages`. Since the page
   was closed inside `fetch_rendered_html()`, `extractor._context.pages` is `[]` (empty).
4. The condition `if pages:` evaluates to `False`, so screenshot capture is skipped
   and returns `None` without attempting to save a file or raising an exception.
